## 1. 产品概述

### 1.1 产品信息

| 属性 | 值 |
|------|-----|
| 产品名称 | AIAgent |
| 页面标题 | AI教育 — 教育设备管理平台 |
| 页面类型 | 登录 / 认证 |
| 技术栈 | 纯静态 HTML5 + CSS3 + 原生 JavaScript |
| 依赖 | 零外部依赖（图标使用内联 SVG） |
| 目标浏览器 | Chrome / Firefox / Safari / Edge 最新两版 |

### 1.2 设计目标

- 打造一个有**情感温度**的登录体验，区别于传统冷冰冰的表单页面
- 通过四个拟人化卡通角色的**微动画**传递品牌个性
- 利用**眼动追踪**交互增强用户参与感和趣味性
- 保持表单区域简洁高效，不过度设计

## 4. 角色系统

### 4.1 角色概览

四个 SVG 角色以层叠方式组成插画群组，共同基线 Y=240。

| 角色 | 颜色 | 形状 | 个性 | 动画 |
|------|------|------|------|------|
| 🟣 **小蓝** | `#6d63ff` | 平顶平行四边形 | 稳重、可靠 | `float-blue` 漂浮 |
| 🟠 **小橙** | `#fc8d70` | 半圆拱形 | 憨厚、慵懒 | `breathe-orange` 呼吸 |
| ⚫ **小黑** | `#1f1f1f` | 圆角矩形 | 机敏、警觉 | `sway-black` 摇摆 |
| 🟡 **小黄** | `#eec53e` | 胶囊形 | 活泼、好动 | `bounce-yellow` 弹跳 |

### 4.2 角色几何规格

```
小蓝 (char-blue) — 漂浮
┌─────────────────────────────────┐
│  polygon: 120,50 → 200,50       │
│           210,240 → 130,240     │
│  高度: 190px (最高)              │
│  眼睛: (135,85) (185,85) r=3.5 │
│  瞳孔活动范围: 3px              │
└─────────────────────────────────┘

小橙 (char-orange) — 呼吸
┌─────────────────────────────────┐
│  path: M30,240 L180,240         │
│        A70,70 (拱形半径70)       │
│  高度: 70px                     │
│  眼睛: (95,190) (115,190) r=2.5│
│  瞳孔活动范围: 3px              │
└─────────────────────────────────┘

小黑 (char-black) — 摇摆
┌─────────────────────────────────┐
│  rect: x=180 y=100              │
│        w=65 h=140 rx=8          │
│  高度: 140px                    │
│  眼睛: (195,125) (225,125) r=3  │
│  嘴: (200,165) 24×4 rx=2        │
└─────────────────────────────────┘

小黄 (char-yellow) — 弹跳
┌─────────────────────────────────┐
│  rect: x=245 y=120              │
│        w=70 h=120 rx=35         │
│  高度: 120px                    │
│  眼睛: (265,140) (295,140) r=3  │
│  嘴: (270,165) 30×4 rx=2        │
└─────────────────────────────────┘
```

### 4.3 角色层叠顺序（从底到顶）

```
1. 小蓝 (紫色) — 最底层，跨度最大
2. 小橙 (橙色) — 覆盖小蓝左下部
3. 小黑 (黑色) — 覆盖小蓝右下部
4. 小黄 (黄色) — 最上层最右侧
```

## 5. 动画系统

### 5.1 角色独立动画

| 动画名称 | 目标 | 时长 | 缓动 | 描述 |
|----------|------|------|------|------|
| `float-blue` | `#char-blue` | 4s | `ease-in-out` | 上下漂浮 ±12px + 微旋转 ±1° |
| `breathe-orange` | `#char-orange` | 3.5s | `ease-in-out` | 缩放 Y: 0.94~1.05，模拟呼吸 |
| `sway-black` | `#char-black` | 3s | `ease-in-out` | 左右摇摆 ±2° + 位移 ±4px |
| `bounce-yellow` | `#char-yellow` | 2.8s | `ease-in-out` | 弹跳 18px + 压扁回弹效果 |

### 5.2 共享动画

| 动画名称 | 目标 | 时长 | 描述 |
|----------|------|------|------|
| `blink` | `.eye-white` | 4s | 93% 处瞬间闭眼（scaleY→0.05） |

眨眼节奏错开：小蓝 0s → 小黄 0.7s → 小橙 1.3s → 小黑 2.6s

### 5.3 交互动画

| 触发条件 | 动画 | 实现 |
|----------|------|------|
| 输入框聚焦 | `stretch-neck` | 群组上移 15px + 缩放 1.04，角色独立动画暂停 |
| 密码明文可见 | `turn-away` | 群组 Y轴旋转 180° + 上移 10px，瞳孔追踪暂停，角色独立动画暂停 |
| 失去焦点 | 恢复 | 移除 stretch-neck，恢复角色动画 |
| 密码隐藏 | 恢复 | 移除 turn-away，恢复角色动画和瞳孔追踪 |

### 5.4 眼动追踪

```
鼠标移动 → 计算瞳孔中心与鼠标的 δx, δy
         → 限制在 data-range 范围内（3px）
         → translate(dx, dy) 跟随鼠标
         → turn-away 状态下暂停
```

## 8. 交互流程

### 8.1 完整交互状态机

```
                    ┌─────────┐
          页面加载 → │  空闲态  │ ←──────────────┐
                    └────┬─────┘                │
                         │                      │
              聚焦输入框  │                      │ 失焦
                         ▼                      │
                    ┌─────────┐                │
                    │ 探头态   │ ───────────────┘
                    │ stretch │
                    └────┬─────┘
                         │
           点击眼睛图标   │
                         ▼
                    ┌─────────┐
                    │ 转身态   │
                    │ turn-away│
                    └────┬─────┘
                         │
           再次点击眼睛    │
                         ▼
                    ┌─────────┐
                    │  空闲态  │
                    └─────────┘
```

### 8.2 瞳孔追踪流程

```
mousemove 事件
  │
  ├─ turn-away? ──是──→ return (跳过)
  │
  └─ 否 → 遍历所有 .pupil
            │
            ├─ 计算 eyeCenter (getBoundingClientRect)
            ├─ δx = mouseX - eyeCenterX
            ├─ δy = mouseY - eyeCenterY
            ├─ 限制在 data-range 内 (px)
            └─ 应用 transform: translate(δx, δy)
```

## 9. 技术架构

### 9.1 文件结构

```
LoginPage/

└── docs/
    └── design-v0.1.md      ← 本设计文档
```

### 9.2 技术选型理由

| 决策 | 理由 |
|------|------|
| 纯静态单文件 | 零构建、零部署、直接浏览器打开 |
| CSS 变量 | 统一管理主题色，便于后续换肤 |
| 内联 SVG 图标 | 离线可用，无 CDN 依赖，支持 `currentColor` |
| 原生 JS | 无框架开销，体量小 |
| CSS Animation | GPU 加速，不阻塞主线程 |

### 9.3 浏览器兼容性

| 特性 | Chrome | Firefox | Safari | Edge |
|------|--------|---------|--------|------|
| CSS 变量 | ✓ | ✓ | ✓ | ✓ |
| CSS Animation | ✓ | ✓ | ✓ | ✓ |
| CSS `transform-style: preserve-3d` | ✓ | ✓ | ✓ | ✓ |
| SVG `currentColor` | ✓ | ✓ | ✓ | ✓ |
| `getBoundingClientRect` | ✓ | ✓ | ✓ | ✓ |
| `classList` | ✓ | ✓ | ✓ | ✓ |
